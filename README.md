# Hero — текстовая RPG на Python



## Особенности
- Пошаговая боевая система с уникальными способностями боссов.
- Инвентарь и экипировка героя.
- Случайная генерация комнат подземелья.
- Сохранение прогресса в JSON.

## Как запустить
1. Установите Python 3.8 или выше.
2. Скачайте репозиторий.
3. В терминале в папке проекта выполните:
   ```bash
   python main.py
